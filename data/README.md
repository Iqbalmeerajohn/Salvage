# SYNTHETIC DATA — not real

Every record in this directory is generated by `salvage/synth.py` with a
fixed seed (20260905). No real person, card, bank, or merchant is represented.
Amounts are integer paise. This exists so SALVAGE can be demonstrated without
a live merchant.

- customers: 62
- products: 8
- payments: 441 (88 failed)

Hero cases (deterministic ids used by the demo):
- `pay_hero_refuse` — churn-risk customer, 2 incentives in 30d → SALVAGE refuses.
- `pay_hero_recover` — healthy VIP, OTP drop → capped incentive, needs approval.
- `pay_hero_bankdown` — bank downtime → forced switch-rail, no money.
